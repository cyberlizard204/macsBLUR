# Welcome to macsBLUR

Welcome to another thrilling instalment in the 'Macs' range of software.  This super small utility is written entirely in Swift and has one sole purpose in life... to reduce visible distraction.  In many ways it is reminiscent of the old x-eyes application from many years ago when Linux was just beginning to get established, though I have not included mouse tracking in this app.

So what does it do... it either blurs background application windows, or it darkens them, or it does both.  That's about as simple as it gets.
